## ⚡ Key Features

* **🎡 Smooth Canvas Wheel Physics**: High-FPS animation with authentic deceleration physics, glowing pointer deflection, particle sparks, and Web Audio API synthesized tick sounds.
* **🔨 Complete Bidding & Draft Arena**:
  * **Starting Base Bids**: Strictly calibrated under **₹ 12,000 INR** based on power levels.
  * **Trainer Purse**: Configurable between **₹ 1,00,000 (1 Lakh min)** and **₹ 2,00,000 (2 Lakhs max)**.
  * **Party Capacity**: Max 5 draft picks per player.
  * **Host Discard Privilege**: Only Player 1 (Host) has permission to discard/release wild encounters.
  * **3 Bidding Modes**: Live Auction (1-by-1 with quick raises), Secret Blind Bidding (hidden inputs), and Direct Assign.
* **⚔️ Squad vs Squad Combat**: Deploy your drafted 5-character squad in simulated combat with floating damage numbers, critical hits, and combat logs.
* **🐉 Co-Op Raid Boss Arena (Pokémon)**:
  * **5 Tiered Raid Bosses**: Mewtwo (Tier 1), Primal Titans (Tier 2), Mega Rayquaza (Tier 3), Ultra Necrozma (Tier 4), and Supreme Arceus (Tier 5).
  * **Gen 9 Type Matchup Engine**: Super effective (2.0×), resistant (0.5×), and immune (0×) calculations.
  * **✨ TERA BURST**: Once-per-battle Terastallization granting a 2.5× apocalyptic damage boost.
  * **Boss Enrage Aura**: Screen shakes and pulsating crimson auras when boss HP falls below 50%.
  * **🏆 Badge Case**: Claim 5 unlockable metallic badges and MVP purse rewards (+₹ 25,000 INR).
* **🔴 Authentic Pokéball Catch Animation**: Drops with physics bounces, wiggles 3 times with sound ticks, snaps shut with gold stars, and plays the victory jingle!

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Google Chrome, Edge, Firefox, Safari).
3. No build tools, Node.js, or servers required — it runs 100% client-side with pure HTML, CSS, and Vanilla JavaScript!

## 🌐 Deploy Free to GitHub Pages

1. Create a new repository on GitHub (e.g. `multiverse-master-wheel`).
2. Push your code:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Multiverse Master Suite"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/multiverse-master-wheel.git
   git push -u origin main
   ```
3. Go to your repository on GitHub:
   * Click **Settings** > **Pages** (in the left sidebar).
   * Under **Branch**, select `main` and `/ (root)`.
   * Click **Save**.
4. In about 60 seconds, your game will be live for everyone at:  
   `https://<YOUR_USERNAME>.github.io/multiverse-master-wheel/`
